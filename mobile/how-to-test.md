# 怎么跑起来看效果

## 先说明一下：后端不用单独启动

这个版本没有真正的服务器，「后端」是模拟的，直接写在 App 里面，数据只存在手机上。所以**不需要另外启动什么后端**，把 App 跑起来就能用。

电脑上要开的只有 Expo 的开发服务器。它负责把代码送到手机上，顺便查地名、出静态地图（这两项要配 key，下面会说，不配也能用）。

## 准备工作（只做一次）

1. 电脑装好 Node.js 24 或更新的版本。
2. 打开终端，进到项目的 `mobile` 文件夹，装依赖：

   ```bash
   cd mobile
   npm install
   ```

3. （可选）想让地名显示中文、有静态底图和街景，就在 `mobile` 文件夹里建一个 `.env` 文件，写上：

   ```
   AMAP_WEB_SERVICE_KEY=你的高德 Web 服务 key
   BAIDU_PANORAMA_AK=你的百度全景 AK
   ```

   不写也能跑。这时地名用手机系统自带的地理编码，手机是英文系统就会显示英文地名。

## 方法一：用手机上的 Expo Go（最快）

1. iPhone 上去 App Store 装 **Expo Go**。
2. 电脑上在 `mobile` 文件夹里运行：

   ```bash
   npx expo start
   ```

3. 终端里会出一个二维码，用 iPhone 相机扫一下，就会在 Expo Go 里打开。
   - 手机和电脑最好连同一个 Wi-Fi。
   - 不在同一个网络、或者扫了打不开，就换成 `npx expo start --tunnel` 再扫。
4. 想在电脑的 iPhone 模拟器里看，在运行 `npx expo start` 的终端里按一下 `i` 就行（要先装 Xcode）。

注意：Expo Go 里**没有可拖动的地图**。发现页的「地图」视图会提示去用开发版本，地点页的小地图会变成静态图。其他功能都正常。

## 方法二：在 Mac 上装完整版（能看地图）

需要 Mac 和 Xcode。在 `mobile` 文件夹里运行：

```bash
npx expo run:ios
```

第一次会比较慢（要编译几分钟）。编译完会自动打开 iPhone 模拟器，装上 App 并打开，地图功能都能用。

- 模拟器没有摄像头，发布留话时点「使用演示照片（模拟拍摄）」就行。
- 这条命令有时候会顺手改掉 `package.json` 里 `ios`、`android` 那两行脚本，改回去就好，别提交。

## 打开之后怎么体验

1. 第一次打开会到欢迎页，点「先逛逛」，或者选一个模拟登录（微信 / Apple / 游客，都是假的）。
2. 系统问要不要给定位，点允许。
3. **人不在演示地点附近也没关系**：
   - 点发现页左上角的头像进「我」，再进「演示与模拟」。
   - 位置模式选「模拟位置」。
   - 点「把演示地点移到我附近」。
4. 回到发现页，能看到附近的留话卡片。离得远只能看到「这里有人留过话」，走近一点能看到预览，到现场才能看全文。
   - 在模拟位置下，点进一个地点，用「模拟走近」「模拟到场」就能看到内容一点点解锁。
5. 底部中间的「留下」可以自己发一条留话：拍照（或用演示照片）、写一句话、点「留在这里」。
6. 想看有人来回复：在「演示与模拟」里打开「模拟其他用户」，过一会儿会有模拟用户回复、点赞，还会发来私聊申请，都在「消息」里。
7. 私聊次数用完了，在「演示与模拟」里点「领取演示权益」。
8. 想从头再来：「演示与模拟」最下面点「重置演示数据」。

## 常见问题

- **App 打开是红屏，说连不上**：电脑上的 `npx expo start` 没开，或者被关掉了，重新运行一下。
- **扫码后一直转圈打不开**：换成 `npx expo start --tunnel` 再扫一次。
- **地名是英文**：没配高德 key，用的是手机系统的地名，跟着手机语言走。配了 key 就会是中文。
- **改了代码手机上没变**：摇一下手机（模拟器按 Ctrl + Cmd + Z）调出菜单，点 Reload。
